1. 接口描述
接口请求域名： trtc.tencentcloudapi.com 。

成功开启录制后，可以使用此接口来查询录制状态。仅在录制任务进行时有效，录制退出后查询将会返回错误。
录制文件上传到云点播VOD时，StorageFileList中不会返回录制文件信息，请订阅相关录制文件回调事件，获取录制文件信息。

默认接口请求频率限制：20次/秒。

推荐使用 API Explorer
点击调试
API Explorer 提供了在线调用、签名验证、SDK 代码生成和快速检索接口等能力。您可查看每次调用的请求内容和返回结果以及自动生成 SDK 调用示例。
2. 输入参数
以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 公共请求参数。

参数名称	必选	类型	描述
Action	是	String	公共参数，本接口取值：DescribeCloudRecording。
Version	是	String	公共参数，本接口取值：2019-07-22。
Region	是	String	公共参数，详见产品支持的 地域列表，本接口仅支持其中的: ap-beijing, ap-guangzhou, ap-shanghai 。
SdkAppId	是	Integer	TRTC的SDKAppId，和录制的房间所对应的SDKAppId相同。
示例值：1400***366
TaskId	是	String	录制任务的唯一Id，在启动录制成功后会返回。
示例值：-m9jKgBv***dPBQE.
RecorderKey	否	String	转推录制任务发起时所填，标识一次录制
示例值：recorder_key_test
3. 输出参数
参数名称	类型	描述
TaskId	String	录制任务的唯一Id。
示例值：-m9jKgBv***dPBQE.
Status	String	云端录制任务的状态信息。
Idle：表示当前录制任务空闲中
InProgress：表示当前录制任务正在进行中。
Exited：表示当前录制任务正在退出的过程中。
示例值：InProgress
StorageFileList	Array of StorageFile	录制文件信息。
示例值：[{"FileName": "***_main_audio.m3u8","UserId": "jeff3","TrackType": "audio","BeginTimeStamp": 1730087526709}]
RecorderKey	String	转推录制任务发起时所填，标识一次录制
示例值：recorder_key_test
RequestId	String	唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。
4. 示例
示例1 查询SdkAppId 为 1400366 TaskId 为 m9-bVVU7nhKM5X3GsED6KNGVG*ndibWSn631uT6pbhE4PcPDSsggE.的录制状态。
输入示例
POST / HTTP/1.1
Host: trtc.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeCloudRecording
<公共请求参数>

{
    "TaskId": "m9-bVVU7nhKM5X3GsED6KNGVG********ndibWSn631uT6pbhE4PcPDSsggE.",
    "SdkAppId": 1400188366
}
输出示例
{
    "Response": {
        "Status": "InProgress",
        "StorageFileList": [],
        "RequestId": "c4536bd1-c3ea-4e84-b2dd-a8491d2057e2",
        "TaskId": "m9-bVVU7nhKM5X3GsED6KNGVG********ndibWSn631uT6pbhE4PcPDSsggE."
    }
}
